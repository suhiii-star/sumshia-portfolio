## Replace the profile image

Replace:

```text
assets/images/profile-placeholder.png
```

with your own image using the same filename, or change the image path in `index.html`.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. Wait a few minutes for the live website link.

Before submitting, verify that:

- The repository is public.
- `index.html` is in the repository root.
- The live website opens in an incognito/private browser window.
- All images, paper and certificate buttons work.
